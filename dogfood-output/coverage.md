# Карта проверок

Статусы: `не начато`, `в работе`, `проверено`, `ограничено`. Эта карта показывает охват, а не обещает отсутствия ошибок.

| Область | Основные сценарии | Статус |
|---|---|---|
| Витрина: главная и навигация | ссылки, меню, категории, ошибки загрузки | в работе |
| Каталог | сортировка, категории, карточки, пустые состояния | в работе |
| Товар | варианты, цена, наличие, добавление в корзину | в работе |
| Корзина и заказ | количество, удаление, адрес, доставка, оплата, подтверждение | в работе: заказ №15 создан и проведён через статусы заказа |
| Аккаунт покупателя | регистрация, вход, профиль, адреса, сброс пароля, заказы | в работе: регистрация, вход, профиль и адрес проверены |
| Админка: вход и обзор | вход, выход, доступ без сессии, навигация | в работе |
| Админка: каталог | создание, изменение, удаление тестовых данных | в работе |
| Админка: склад | список остатков и резервирований, создание запасов | в работе: списки и резервирования просмотрены |
| Админка: продажи | заказы, клиенты, скидки, прайс-листы, возвраты при наличии | в работе: на заказе №15 проверены захват €30, fulfillment, отправка, доставка и частичный возврат €5; промокоды и черновой прайс-лист проверены |
| API | успешные ответы, ошибки, согласованность с интерфейсом | в работе: Store API, отсутствие ключа и авторизации, статус Draft |

## Критерии при отсутствии требований

Опираемся на обещания самого интерфейса, согласованность UI и API, обычные сценарии интернет-магазина и общепринятые правила доступности. Для неоднозначных продуктовых решений пишем наблюдение или вопрос, а не объявляем их багом.
